# ابدأ من هنا — حزمة Cursor الكاملة

هذه الحزمة الخارجية تحتوي ملفين مصدر مستقلين:

1. `01-ORIGINAL/ORIGINAL-V2-5-9-SOURCE.zip`: النسخة الأصلية المؤرخة 1 أغسطس 2026.
2. `02-CURRENT/CURRENT-FINAL-RESTORE-SOURCE.zip`: النسخة الحالية النهائية النظيفة.

وتحتوي أيضًا:

- `03-REPORTS`: تقارير التدقيق والمقارنة والتسليم.
- `04-PROMPT/CURSOR-PROMPT.md`: النص المطلوب نسخه إلى Cursor.
- `MANIFEST.json`: هوية الملفات والبصمات.
- `CONTENTS.sha256`: بصمات الملفات الداخلية الأساسية.

## طريقة الاستخدام

1. فك الحزمة الخارجية في مجلد جديد.
2. افتح Cursor على المجلد الخارجي.
3. انسخ النص الموجود في `04-PROMPT/CURSOR-PROMPT.md` إلى Cursor.
4. اترك النسختين مضغوطتين كما هما حتى يتحقق Cursor من SHA-256، ثم يفك كل واحدة في مجلد منفصل.
5. لا تستخدم أي EXE أو ZIP أقدم خارج هذه الحزمة باعتباره النسخة الحالية.

الحزمة لا تحتوي `node_modules` أو `dist` أو profiles أو tokens أو مجلدات `.codex-*` أو بيانات `license/data` المحلية.

## تحذير أمني خاص بالنسخة الأصلية

النسخة الأصلية محفوظة كما كانت لأغراض المقارنة، وكانت تحتوي مفتاح Ed25519 تطويريًا تاريخيًا تحت أدوات الترخيص. هذا المفتاح ليس مفتاح Production ولا يجوز نسخه إلى النسخة الحالية أو استخدامه أو نشر الحزمة خارج فريق المراجعة. النسخة الحالية النظيفة لا تحتوي المفتاح الخاص التاريخي.
